# Project Statement

## Problem Statement
Manual management of student records, academic marks, attendance, and performance summaries can be repetitive and may lead to calculation or record-keeping errors. A Java application is needed to centralize these operations.

## Scope
Student CRUD, course management, marks, attendance, automatic calculations, reports, class analytics, CSV persistence, validation, error handling, and unit tests.

## Target Users
Students, faculty/mentors, and academic administrators.

## High-Level Features
- Student CRUD
- Course management
- Marks management
- Attendance management
- Individual performance report
- Class summary
- CSV persistence
- Input validation
- JUnit tests

## Expected Outcome
A modular Java application demonstrating practical object-oriented programming and related Java concepts in a real-world academic management scenario.
